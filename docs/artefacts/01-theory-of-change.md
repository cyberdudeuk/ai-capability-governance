# Theory of change: AI Capability Governance and Implementation

> **How to read this.** Facts marked V were read from this repository on 20 November 2026. Assumptions, measures and risks are proposals written for this kit, not findings. U means unconfirmed. Where another document in this repository already covers a topic, this one links to it rather than repeating it.

## Problem
Public servants using AI, and the data it uses, lack practical, proportionate tools to decide how much human review an AI use needs and what evidence to keep.

## Long-term outcome
AI uses in public services get proportionate human review and a clear evidence record, faster.

## Chain

| Inputs | Activities | Outputs | Short-term outcomes | Medium-term outcomes |
|---|---|---|---|---|
| Published public sector AI guidance; the Algorithmic Transparency Recording Standard; NCSC post-quantum migration milestones; plain-language standards | Provide six tools (human review triage, evidence pack, DEIA screen, transparency record, quantum readiness, plain-language checker); a weekly signals digest; user guides by level | A static site with six tools, signals and guides; a playbook; health and triage routines | Users reach an H0 to H5 review level and a declaration in minutes | More AI uses carry evidence records and transparency records |

## Assumptions (proposed; each one testable)

| # | Assumption | How to test it | Evidence today |
|---|---|---|---|
| A1 | Teams will use a triage score to set review effort | Test with 5 users across levels | Not tested |
| A2 | The H0 to H5 model is understood without training | Usability test | Not tested |

## Measures (proposed)
- Next content review on time (13 Feb 2027)
- Signals digest runs weekly (digest workflow)
- Tool outputs match the stated rules (tests/test_site.py)

No target is set before a baseline exists.

## What would prove this wrong
If organisations' own AI assurance processes already give the same answer faster, keep only the signals digest.
