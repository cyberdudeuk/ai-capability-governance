# Accessibility statement

This statement applies to https://cyberdudeuk.github.io/ai-capability-governance/.

We want as many people as possible to be able to use this site. You should be able to change colours, contrast and text
size (the site has light, dark, high-contrast and large-text modes), zoom to 400% without text spilling off the screen,
and navigate with a keyboard, speech recognition or a screen reader. All content is in the HTML and readable without
JavaScript; the tools need JavaScript.

## How accessible this site is

The site is designed to meet WCAG 2.2 level AA. **This has not been independently audited.** Automated checks run on
every change, but they cannot find every barrier. Known limits:

- The interactive tools have not been tested with every screen reader and browser combination.
- Some external sources linked from the resource library are not accessible, and we do not control them.

## Reporting a barrier

Use the [accessibility form](https://github.com/cyberdudeuk/ai-capability-governance/issues/new?template=accessibility_issue.yml). Barriers are treated as
priority defects, with a target first response of five working days. There is no email route.

## Enforcement

If you are not happy with how we respond, contact the
[Equality Advisory and Support Service](https://www.equalityadvisoryservice.com/).

This statement was prepared on 8 November 2026 from the design intent and automated checks, not an audit.
