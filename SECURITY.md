# Security

The site is static. It collects no personal data, sets no cookies, has no analytics and makes no third-party requests.
Every tool runs in your browser and nothing you type leaves it.

To report a vulnerability, use GitHub's private vulnerability reporting: open the **Security** tab of this repository
and select **Report a vulnerability**. Do not open a public issue for a security problem. There is no email route.

## Government vulnerability disclosure

This is UK government work. If you find an exploitable vulnerability, you can also report it through the
Cabinet Office vulnerability disclosure programme: follow
[Report a vulnerability on a GOV.UK system](https://www.gov.uk/help/report-vulnerability), which routes
reports to HackerOne. Please do not report security problems in public issues.
